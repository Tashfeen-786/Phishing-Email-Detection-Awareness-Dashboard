## How the automatic ones were produced

```bash
# Terminal evidence (01, 02, 03, 23) - runs each command and draws its real output
python scripts/render_terminal.py

# Application evidence (04-17) - drives a real browser against the running app
#   start_backend.bat and start_frontend.bat must be running first
pip install playwright && python -m playwright install chromium
python scripts/capture_screenshots.py

# Metric charts (18-22) - written by the training and evaluation scripts
python ml/train_model.py
python ml/evaluation.py
```

`capture_screenshots.py` fails loudly if any page logs a JavaScript error, so a
broken screenshot cannot be mistaken for a working one. On the run that produced
these files it reported *"no JavaScript errors were logged on any page"*.

## Items 24–26 — what you need to do

These three cannot be generated by this project. They show a GitHub repository
that only you can create, under your own account. **No placeholder images have
been supplied, and no repository URL has been invented.**

### Step 1 — create the repository

On [github.com/new](https://github.com/new):

- **Name:** `Phishing-Email-Detection-Awareness-Dashboard`
- **Visibility:** Public
- Do **not** tick "Add a README" — this project already has one.

### Step 2 — push the code

From the project folder:

```bash
git init
git add .
git commit -m "feat: phishing email detection and awareness dashboard"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/Phishing-Email-Detection-Awareness-Dashboard.git
git push -u origin main
```

`.gitignore` already excludes `.env`, `.venv/`, `node_modules/`, the SQLite
database and the trained model. **Check `git status` before your first commit
and confirm no `.env` file is listed.**

For a commit history that reflects how the project was actually built, see the
suggested sequence in [`../docs/GITHUB_STRATEGY.md`](../docs/GITHUB_STRATEGY.md).
